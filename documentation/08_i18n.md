---

## Language Toggle

- The custom AppBar displays two flag icons (PT / EN)
- The active language flag is rendered larger
- Tapping a flag calls `LocaleProvider.setLocale()` and rebuilds the app

---

## Dynamic Content Translation

For backend-provided content (zone names, trail descriptions), the `TranslationHelper` utility:
- Accepts a nested data structure with language-keyed entries
- Returns the value matching the current app locale
- Falls back to a base field value, then to a provided fallback string
